每列：`型別代碼` 中文名 — 接腳 名稱(x,y)類型（rot=0、未鏡像）— 參數=預設值。類型：P 功率、Ci 控制輸入、Co 控制輸出、G 閘極（控制訊號）、A 功率或控制。CBLOCK 的接腳依 nin／nout 變化（見 SKILL.md）。

## 功率元件 › RLC 支路

- `R` 電阻 — pins: 1(-2,0)P 2(2,0)P — R=10Ω
  理想線性電阻，v = R·i。電阻值可為 0（視為短路），不可為負值。
- `L` 電感 — pins: 1(-2,0)P 2(2,0)P — L=1mH, i0=0A
  理想線性電感，v = L·di/dt。以梯形積分法離散化，開關動作後的第一步改用後向尤拉法以抑制數值振盪。電流方向以流入接腳 1（圓點端）為正。
- `C` 電容 — pins: 1(-2,0)P 2(2,0)P — C=100uF, v0=0V
  理想線性電容，i = C·dv/dt。可設定初始電壓。若與電壓源直接並聯且初始電壓不同，t=0 的初始解會以近似值處理並提出警告。
- `RL` R-L 串聯支路 — pins: 1(-3,0)P 2(3,0)P — R=1Ω, L=1mH, i0=0A
  R-L 串聯支路：R、L 串聯成單一支路，以單一支路電流變數求解（v = R·i + L·di/dt + vC）。任一參數設 0 表示該元件不存在，但不可全部為 0。
- `RC` R-C 串聯支路 — pins: 1(-3,0)P 2(3,0)P — R=1Ω, C=100uF, v0=0V
  R-C 串聯支路：R、C 串聯成單一支路，以單一支路電流變數求解（v = R·i + L·di/dt + vC）。任一參數設 0 表示該元件不存在，但不可全部為 0。
- `LC` L-C 串聯支路 — pins: 1(-3,0)P 2(3,0)P — L=1mH, C=100uF, i0=0A, v0=0V
  L-C 串聯支路：L、C 串聯成單一支路，以單一支路電流變數求解（v = R·i + L·di/dt + vC）。任一參數設 0 表示該元件不存在，但不可全部為 0。
- `RLC` R-L-C 串聯支路 — pins: 1(-4,0)P 2(4,0)P — R=1Ω, L=1mH, C=100uF, i0=0A, v0=0V
  R-L-C 串聯支路：R、L、C 串聯成單一支路，以單一支路電流變數求解（v = R·i + L·di/dt + vC）。任一參數設 0 表示該元件不存在，但不可全部為 0。
- `R3` 三相電阻 — pins: A(-2,-1)P B(-2,0)P C(-2,1)P a(2,-1)P b(2,0)P c(2,1)P — R=1Ω
  三相電阻：三相對稱支路，每相各為 R 串聯，初始電流與電容電壓皆為 0。有圓點的一相為 A 相（最上方）。
- `RL3` 三相 R-L 支路 — pins: A(-2,-1)P B(-2,0)P C(-2,1)P a(2,-1)P b(2,0)P c(2,1)P — R=1Ω, L=1mH
  三相 R-L 支路：三相對稱支路，每相各為 R-L 串聯，初始電流與電容電壓皆為 0。有圓點的一相為 A 相（最上方）。
- `RC3` 三相 R-C 支路 — pins: A(-2,-1)P B(-2,0)P C(-2,1)P a(2,-1)P b(2,0)P c(2,1)P — R=1Ω, C=100uF
  三相 R-C 支路：三相對稱支路，每相各為 R-C 串聯，初始電流與電容電壓皆為 0。有圓點的一相為 A 相（最上方）。
- `RLC3` 三相 R-L-C 支路 — pins: A(-2,-1)P B(-2,0)P C(-2,1)P a(2,-1)P b(2,0)P c(2,1)P — R=1Ω, L=1mH, C=100uF

- `RHEO` 可變電阻 — pins: k(-2,0)P m(2,0)P t(0,-2)P — R=10Ω, tap=0.5
  附抽頭的電阻。k–t 之間為 R·Tap，t–m 之間為 R·(1−Tap)。
- `LSAT` 飽和電感 — pins: 1(-2,0)P 2(2,0)P — tab=1 10m 2 6m 5 3m
  考慮鐵心飽和的非線性電感。以 (i, L) 點定義磁通鏈 λ = L·i 的分段線性曲線，模擬時以牛頓法求解。
- `NONI` 非線性元件（電導型） — pins: 1(-2,0)P 2(2,0)P — f=1e-14*(exp(40*v)-1), df=40e-14*exp(40*v), x0=0V, lo=-1000V, hi=1V

- `NONV` 非線性元件（電阻型） — pins: 1(-2,0)P 2(2,0)P — f=10*i+0.1*i^3, df=10+0.3*i^2, x0=0A, lo=-1000A, hi=1000A
  電阻型非線性元件 v = f(i)，以牛頓法求解。

## 控制元件

- `CONST` 常數 — pins: out(2,0)Co — v=1
  常數：輸出固定數值的控制訊號，作為控制迴路的參考值、增益或偏移量（例如電壓命令、PWM 比較的直流準位）。AC 小訊號分析時視為 0。
- `P` 比例控制器 — pins: in(-2,0)Ci out(2,0)Co — k=1
  比例控制器：輸出 = k·輸入。
- `I` 積分器 — pins: in(-2,0)Ci out(2,0)Co — T=1ms, y0=0
  積分器 G(s) = 1/(sT)，以梯形法離散：y(n) = y(n−1) + h/(2T)·[u(n) + u(n−1)]。建議在輸出加限制器避免過度飽和。
- `RESETI` 可重置積分器 — pins: in(-2,0)Ci out(2,0)Co reset(0,2)Ci — T=1ms, y0=0, flag=0
  可由下方控制訊號重置的積分器。邊緣重置：控制訊號上升緣時輸出歸零；準位重置：控制訊號為高時輸出保持為零。
- `DIFF` 微分器 — pins: in(-2,0)Ci out(2,0)Co — T=1ms
  微分器 G(s) = sT，計算為 y = T·[u(t) − u(t−Δt)]/Δt。輸入突變會產生尖峰，建議先經過低通濾波。
- `PI` PI 控制器 — pins: in(-2,0)Ci out(2,0)Co — k=1, T=1ms
  PI 控制器 G(s) = k·(1 + sT)/(sT)。建議在輸出加限制器避免積分飽和。
- `SUM2` 加法器（雙輸入） — pins: in1(-2,0)Ci in2(0,2)Ci out(2,0)Co — k1=1, k2=1
  加法器：輸出 = k1·in1 + k2·in2。左側為輸入 1，下方為輸入 2。
- `SUB2` 減法器 — pins: in+(-2,0)Ci in-(0,2)Ci out(2,0)Co
  減法器：輸出 = in+ − in−，常用於誤差計算（參考值 − 回授值）。
- `SUM3` 加法器（三輸入） — pins: in1(0,-2)Ci in2(-2,0)Ci in3(0,2)Ci out(2,0)Co — k1=1, k2=1, k3=1
  三輸入加法器：輸出 = k1·in1 + k2·in2 + k3·in3，有圓點者（上方）為輸入 1。
- `COMP` 邏輯比較器（控制電路） — pins: in+(-3,-1)Ci in-(-3,1)Ci out(3,0)Co
  控制電路用的理想邏輯比較器（PSIM Comparator）：正輸入大於負輸入時輸出 1，小於時輸出 0，相等時保持前值。實際的比較器 IC（LM393 等）請使用「比較器（開集極）」。輸出變化的瞬間會由兩輸入線性內插求出，搭配開關的切換瞬間內插可得到精確的 PWM 占空比。注意：比較器的正輸入在上方（與運算放大器相反…
- `LIM` 限制器 — pins: in(-2,0)Ci out(2,0)Co — lo=-1, hi=1
  限制器：輸入超出上下限時輸出被箝位在上限或下限，否則輸出等於輸入。

  冪次函數：輸出 = k1·輸入^k2。

- `ABS` 絕對值 — pins: in(-2,0)Ci out(2,0)Co

- `SIGN` 符號函數 — pins: in(-2,0)Ci out(2,0)Co
  符號函數：輸入為正輸出 1、負輸出 −1、0 時輸出 0。

  兩輸入取最大值（Flag=0）或最小值（Flag=1）。

## 控制元件 › 其他功能方塊

- `SAMP` 取樣保持 — pins: in(-2,0)Ci ctrl(0,2)Ci out(2,0)Co
  取樣保持：控制訊號（下方）由低轉高時取樣輸入，並保持到下一次取樣。取樣瞬間由控制訊號交越 0.5 的時間內插求得，取樣值為該瞬間的內插輸入值。
- `LKUP` 查表 — pins: in(-2,0)Ci out(2,0)Co — tab=0 0 1 10 2 15 3 17
  一維查表：兩點之間線性內插，輸入小於第一點或大於最後一點時輸出箝位於端點值。
- `LKUPTZ` 梯形波查表 — pins: in(-2,0)Ci out(2,0)Co — th=30deg, vpk=1
  梯形波查表：輸入為角度（−360°~360°），輸出為具半波及四分之一波對稱的梯形波，上升角 θ、峰值 Vpk。
- `LKUPSQ` 方波查表 — pins: in(-2,0)Ci out(2,0)Co — th=120deg
  方波查表：輸入為角度，輸出為 ±1 的方波，在每半週期中央寬 θ 度，具半波及四分之一波對稱。
- `FFT` 快速傅立葉轉換 — pins: in(-2,0)Ci amp(2,-1)Co phase(2,1)Co — N=64, fb=60Hz
  計算輸入的基本波成分：上方（圓點）輸出為峰值振幅，下方輸出為相位角（度），Vm·sin(ωt) 的相位為 0。取樣時刻精確對齊 k/(N·fb)。
- `TFS` s 域轉移函數 — pins: in(-2,0)Ci out(2,0)Co — k=1, num=0 1, den=1e-3 1
  G(s) = k·(Bn·sⁿ + … + B0)/(An·sⁿ + … + A0)。轉成可觀測標準型狀態方程式並以梯形法離散，與功率電路的積分法一致。例：1.5·400e3/(s² + 1200s + 400e3) 輸入 k=1.5、分子 "0 0 400e3"、分母 "1 1200 400e3"。
- `TFS1` s 域轉移函數（含初值） — pins: in(-2,0)Ci out(2,0)Co — k=1, num=0 1, den=1e-3 1, x0=0
  與 s 域轉移函數相同，但可設定狀態變數初始值（PSIM TFCTN1）。
- `TDELAY` 時間延遲 — pins: in(-2,0)Ci out(2,0)Co — Td=1ms
  連續時間延遲：將輸入波形延遲指定時間。輸入中的跳變（例如數位訊號邊緣）會被精確記錄並在延遲後的時刻準確重現（設為模擬斷點）。
- `UTD` 單位時間延遲 — pins: in(-2,0)Ci out(2,0)Co
  延遲一個模擬時間步：輸出 = 上一個計算點的輸入。可用來打斷控制電路中的代數迴路。
- `THD` 總諧波失真 — pins: in(-2,0)Ci THD(2,-1)Co v1(2,1)Co — f=60Hz, fb=20Hz
  總諧波失真 THD = √(Vrms² − V1²)/V1。以二階帶通濾波器擷取基本波 v1(t)（下方輸出），上方輸出為 THD。【啟動不準】帶通濾波器與一週期移動均方根需要時間收斂：輸出在訊號出現後約 3/fb 秒才可信（誤差 < 1%；fb = 20 Hz → 0.15 s，fb = 10 Hz → 0.33 s…
- `ROUND` 四捨五入 — pins: in(-2,0)Ci out(2,0)Co — N=0, flag=0
  捨入方塊：輸入先乘以 10^N，再四捨五入（或截斷），最後除以 10^N。例：34.5678、N=1、截斷 → 34.5。
- `LIMDVDT` 變化率限制器 — pins: in(-2,0)Ci out(2,0)Co — L=10001/s
  限制輸入的變化率，若變化率在範圍內則輸出等於輸入。
- `MUX2` 2 輸入多工器 — pins: d0(-2,-1)Ci d1(-2,0)Ci s0(0,2)Ci Y(2,0)Co
  2 輸入多工器：依選擇訊號 s0（> 0.5 為 1）輸出 d0~d1 其中之一，資料可為類比或數位訊號。
- `MUX4` 4 輸入多工器 — pins: d0(-2,-2)Ci d1(-2,-1)Ci d2(-2,0)Ci d3(-2,1)Ci s0(1,3)Ci s1(-1,3)Ci Y(2,0)Co
  4 輸入多工器：依選擇訊號 s1、s0（> 0.5 為 1）輸出 d0~d3 其中之一，資料可為類比或數位訊號。
- `MUX8` 8 輸入多工器 — pins: d0(-2,-4)Ci d1(-2,-3)Ci d2(-2,-2)Ci d3(-2,-1)Ci d4(-2,0)Ci d5(-2,1)Ci d6(-2,2)Ci d7(-2,3)Ci s0(2,5)Ci s1(0,5)Ci s2(-2,5)Ci Y(2,0)Co
  8 輸入多工器：依選擇訊號 s2、s1、s0（> 0.5 為 1）輸出 d0~d7 其中之一，資料可為類比或數位訊號。
- `ABC2DQO` abc→dqo 轉換 — pins: a(-3,-2)Ci b(-3,-1)Ci c(-3,0)Ci θ(-3,1)Ci d(3,-1)Co q(3,0)Co o(3,1)Co
  abc → dqo 轉換：vd = 2/3·[va·cosθ + vb·cos(θ−2π/3) + vc·cos(θ+2π/3)]，vq 以 sin 計算，vo = (va+vb+vc)/3。θ 單位為弧度。
- `DQO2ABC` dqo→abc 轉換 — pins: d(-3,-2)Ci q(-3,-1)Ci o(-3,0)Ci θ(-3,1)Ci a(3,-1)Co b(3,0)Co c(3,1)Co
  dqo → abc 反轉換：va = vd·cosθ + vq·sinθ + vo，vb、vc 相角分別減、加 2π/3。θ 單位為弧度。

## 控制元件 › 邏輯元件

- `AND` 及閘 — pins: in1(-3,-1)Ci in2(-3,1)Ci out(3,0)Co
  及閘：輸入大於 0.5 視為邏輯 1，輸出為 0 或 1。輸出變化時會沿用造成變化之輸入的精確事件時間（例如比較器的交越時刻）。
- `AND3` 三輸入及閘 — pins: in1(-3,-1)Ci in2(-3,0)Ci in3(-3,1)Ci out(3,0)Co
  三輸入及閘：輸入大於 0.5 視為邏輯 1，輸出為 0 或 1。輸出變化時會沿用造成變化之輸入的精確事件時間（例如比較器的交越時刻）。
- `OR` 或閘 — pins: in1(-3,-1)Ci in2(-3,1)Ci out(3,0)Co
  或閘：輸入大於 0.5 視為邏輯 1，輸出為 0 或 1。輸出變化時會沿用造成變化之輸入的精確事件時間（例如比較器的交越時刻）。
- `OR3` 三輸入或閘 — pins: in1(-3,-1)Ci in2(-3,0)Ci in3(-3,1)Ci out(3,0)Co
  三輸入或閘：輸入大於 0.5 視為邏輯 1，輸出為 0 或 1。輸出變化時會沿用造成變化之輸入的精確事件時間（例如比較器的交越時刻）。
- `XOR` 互斥或閘 — pins: in1(-3,-1)Ci in2(-3,1)Ci out(3,0)Co
  互斥或閘：輸入大於 0.5 視為邏輯 1，輸出為 0 或 1。輸出變化時會沿用造成變化之輸入的精確事件時間（例如比較器的交越時刻）。
- `NOT` 反閘 — pins: in1(-2,0)Ci out(2,0)Co
  反閘：輸入大於 0.5 視為邏輯 1，輸出為 0 或 1。輸出變化時會沿用造成變化之輸入的精確事件時間（例如比較器的交越時刻）。
- `NAND` 反及閘 — pins: in1(-3,-1)Ci in2(-3,1)Ci out(3,0)Co
  反及閘：輸入大於 0.5 視為邏輯 1，輸出為 0 或 1。輸出變化時會沿用造成變化之輸入的精確事件時間（例如比較器的交越時刻）。
- `NOR` 反或閘 — pins: in1(-3,-1)Ci in2(-3,1)Ci out(3,0)Co
  反或閘：輸入大於 0.5 視為邏輯 1，輸出為 0 或 1。輸出變化時會沿用造成變化之輸入的精確事件時間（例如比較器的交越時刻）。
- `SRFF` SR 正反器 — pins: S(-3,-1)Ci R(-3,1)Ci Q(3,-1)Co Qn(3,1)Co — flag=0
  SR 正反器。邊緣觸發：S 上升緣輸出 Q=1，R 上升緣輸出 Q=0；準位觸發：S=1、R=0 時 Q=1，S=0、R=1 時 Q=0，皆為 0 時保持。S、R 同時有效為禁止狀態（保持）。
- `JKFF` JK 正反器 — pins: J(-3,-1)Ci CLK(-3,0)Ci K(-3,1)Ci Q(3,-1)Co Qn(3,1)Co
  JK 正反器，時脈上升緣觸發：J=K=0 保持、J=0/K=1 清除、J=1/K=0 設定、J=K=1 反轉。J、K 取時脈邊緣前一刻的值。
- `JKFFSR` JK 正反器（含設定/重置） — pins: S(0,-3)Ci J(-3,-1)Ci CLK(-3,0)Ci K(-3,1)Ci R(0,3)Ci Q(3,-1)Co Qn(3,1)Co
  含非同步設定 (S) 與重置 (R) 的 JK 正反器：S=1 立即令 Q=1，R=1 立即令 Q=0（高電位有效），否則依時脈上升緣運作。
- `DFF` D 正反器 — pins: D(-3,-1)Ci CLK(-3,1)Ci Q(3,-1)Co Qn(3,1)Co
  D 正反器，時脈上升緣將 D 的值鎖入 Q。
- `DFFSR` D 正反器（含設定/重置） — pins: S(0,-3)Ci D(-3,-1)Ci CLK(-3,1)Ci R(0,3)Ci Q(3,-1)Co Qn(3,1)Co
  含非同步設定/重置的 D 正反器。
- `MONO` 單擊多諧振盪器 — pins: in(-3,0)Ci Q(3,-1)Co Qn(3,1)Co — W=1ms
  單擊電路：輸入上升緣觸發，輸出產生指定寬度的脈波（脈波期間不再重新觸發）。脈波結束時刻精確設為模擬斷點。
- `MONOC` 可控單擊電路 — pins: in(-3,0)Ci W(0,3)Ci Q(3,-1)Co Qn(3,1)Co
  可控單擊電路：脈寬（秒）由下方輸入在觸發瞬間決定。
- `PWCT` 脈寬計數器 — pins: in(-2,0)Ci out(2,0)Co
  脈寬計數器：輸入上升緣開始計時，下降緣時輸出該脈波寬度（秒），並保持到下一個下降緣。邊緣時刻以內插精確求得。
- `UPDN` 上/下數計數器 — pins: U(-3,-1)Ci D(-3,0)Ci R(-3,1)Ci out(3,0)Co — bits=8
  上/下數計數器：UP 上升緣加 1、DN 上升緣減 1，R 為高時清除為 0。輸出為整數計數值。
- `ADC` A/D 轉換器 — pins: Vin(-3,-1)Ci Vref(0,-3)Ci CLK(-3,1)Ci out(3,0)Co — bits=8
  A/D 轉換器：時脈上升緣取樣，輸出 = floor(2^N/Vref·Vin)，限制在 0 ~ 2^N−1。例：Vref=5、Vin=3.2、N=8 → 163。
- `DAC` D/A 轉換器 — pins: Vin(-3,0)Ci Vref(0,-3)Ci out(3,0)Co — bits=8
  D/A 轉換器：輸出 = Vref/2^N·Vin。例：Vref=5、Vin=163、N=8 → 3.1836。

## 控制元件 › 數位控制模組

- `ZOH` 零階保持 — pins: in(-2,0)Ci out(2,0)Co — fs=10kHz
  零階保持：在取樣時刻取樣輸入，並保持到下一個取樣時刻。
- `UDELAY` 單位延遲 1/z — pins: in(-2,0)Ci out(2,0)Co — fs=10kHz
  單位延遲：輸出 = 前一個取樣時刻的輸入（延遲一個取樣週期）。
- `ID` 離散積分器 — pins: in(-2,0)Ci out(2,0)Co — alg=0, y0=0, fs=10kHz
  離散積分器（T = 1/fs）：梯形法 y(n) = y(n−1) + T/2·[u(n)+u(n−1)]；後向尤拉 y(n) = y(n−1) + T·u(n)；前向尤拉 y(n) = y(n−1) + T·u(n−1)。
- `IRSTD` 外部重置積分器 — pins: in(-2,0)Ci reset(0,2)Ci out(2,0)Co — alg=0, y0=0, flag=0, fs=10kHz
  可由外部訊號（下方）重置的離散積分器；邊緣重置於取樣時偵測到上升緣即歸零，準位重置在訊號為高時歸零。
- `IRSTI` 內部重置積分器 — pins: in(-2,0)Ci out(2,0)Co — alg=0, y0=0, lo=0, hi=360, fs=10kHz
  內部重置積分器：輸出超過上限時減去 (上限 − 下限)，低於下限時加上 (上限 − 下限)，形成環繞，常用於產生 0~360° 或 0~2π 的角度。
- `DD` 離散微分器 — pins: in(-2,0)Ci out(2,0)Co — fs=10kHz
  離散微分器 H(z) = (1/T)·(z − 1)/z，y(n) = [u(n) − u(n−1)]/T。
- `FIR` FIR 濾波器 — pins: in(-2,0)Ci out(2,0)Co — b=0.25 0.25 0.25 0.25, fs=10kHz
  有限脈衝響應濾波器 H(z) = b0 + b1·z⁻¹ + … + bN·z⁻ᴺ。
- `FILTD` 數位濾波器 (IIR) — pins: in(-2,0)Ci out(2,0)Co — b=0.0201 0.0402 0.0201, a=1 -1.561 0.6414, fs=10kHz
  一般數位濾波器 H(z) = (b0 + b1·z⁻¹ + … + bN·z⁻ᴺ)/(a0 + a1·z⁻¹ + … + aN·z⁻ᴺ)。例：fc=1kHz、fs=10kHz 二階 Butterworth：b = 0.0201 0.0402 0.0201、a = 1 −1.561 0.6414。
- `TFZ` z 域轉移函數 — pins: in(-2,0)Ci out(2,0)Co — b=0.0201 0.0402 0.0201, a=1 -1.561 0.6414, fs=10kHz
  z 域轉移函數 H(z) = (b0·zᴺ + … + bN)/(a0·zᴺ + … + aN)，等效差分方程式 y(n) = [Σbi·u(n−i) − Σai·y(n−i)]/a0。
- `DIGIT` 量化方塊 — pins: in(-2,0)Ci out(2,0)Co — N=8, vimin=0, vimax=5, vomin=0, vomax=255, fs=10kHz
  量化方塊（模擬 A/D 量化誤差）：先將輸入由 [Vin_min, Vin_max] 線性映射到 [Vo_min, Vo_max]，再依解析度 ΔV = (Vo_max − Vo_min)/(2^N − 1) 向下截斷。
- `DIGIT2` 量化方塊（含偏移） — pins: in(-2,0)Ci out(2,0)Co — N=8, vimin=0, vimax=5, vomin=0, vomax=255, fs=10kHz
  量化方塊（含 ½ LSB 偏移）：與量化方塊相同，但量化採四捨五入至最接近的階層，而非向下截斷。
- `CBUF` 環形緩衝區 — pins: in(-2,0)Ci out(2,0)Co — L=4, fs=10kHz
  環形緩衝區：每個取樣時刻依序寫入，到達尾端後從頭覆寫。輸出為向量，需搭配 Memory Read 讀取個別位置。
- `ARRAY` 資料陣列 — pins: out(2,0)Co — L=4, vals=2 4 6 8
  一維資料陣列（向量常數）。
- `CONV` 摺積 — pins: A(-2,0)Ci B(0,2)Ci out(2,0)Co
  兩向量的摺積，輸出向量長度 m+n−1。例：[1 2 3] ⊗ [4 5] = [4 13 22 15]。
- `MEMREAD` 記憶體讀取 — pins: in(-2,0)Ci out(2,0)Co — off=0
  讀取向量（陣列、環形緩衝區、摺積輸出）中指定位置的值。例：A = [2 4 6 8]，偏移 2 → 輸出 6。
- `STACK` 堆疊 — pins: Vin(-3,-1)Ci push(-3,0)Ci pop(-3,1)Ci out(3,0)Co — depth=8
  先進後出暫存器：push 上升緣存入、pop 上升緣移除頂端；輸出為目前堆疊頂端的值（推入後為剛存入的值，取出後為新的頂端值）。堆疊滿時最底層資料被擠出；堆疊清空或空堆疊 pop 時輸出保持不變。

## 其他 › 開關控制器

- `ONCTRL` 開關控制器 — pins: in(-2,0)Ci gate(2,0)Co
  開關控制器：將控制電路的邏輯訊號（0/1）傳遞給功率開關的閘極，是控制電路與功率開關之間的介面。比較器等產生的精確切換時刻會一併傳遞。
- `ACTRL` 觸發角控制器 — pins: alpha(-3,-1)Ci sync(-3,0)Ci enable(-3,1)Ci gate(3,0)Co — f=60Hz, pw=90deg
  閘流體觸發角控制器：同步訊號由低轉高的瞬間代表 α = 0，延遲 α 度後輸出指定寬度的觸發脈波；enable 為低時停止輸出。α 輸入單位為度，可即時變化。脈波起訖時刻精確設為模擬斷點。
- `GATING` 閘極脈波產生器 — pins: gate(2,0)Co — f=2000Hz, n=2, pts=0 180deg

- `ADCM` 直流電流表 — pins: in(-2,0)P out(2,0)P — fc=10Hz
  直流電流表：串接於支路中，以低通濾波器取電流平均值。
- `AACM` 交流電流表 — pins: in(-2,0)P out(2,0)P — f=60Hz, fc=10Hz
  交流電流表：高通濾波去除直流後計算移動均方根值。
- `WATT` 瓦特計 — pins: I+(-2,0)P I-(2,0)P V-(0,2)P — fc=10Hz
  瓦特計：電流由 I+ 流向 I−，電壓取 I+ 相對 V− 的電壓，讀值為 v·i 經低通濾波後的平均功率。
- `WH3` 三相瓦時計 — pins: A+(-2,-2)P A-(2,-2)P B+(-2,0)P B-(2,0)P C+(-2,2)P C-(2,2)P N(0,3)P — unit=Wh, e0=0
  三相瓦時計（電能表）：A、B、C 三相電流分別由 A+ 流入、A− 流出（依此類推），各相電壓取 A+、B+、C+ 相對 N 的電壓，讀值為三相瞬時功率 va·ia + vb·ib + vc·ic 對時間的積分（每個時間步以梯形法累積），即從模擬開始累積的電能。三相四線系統 N 接中性線；三相三線系統 N 可接任何一點…
- `DEVP` 元件內部探棒 — pins: — — el=Q1, q=p
  元件內部探棒：不需接線，直接讀取指定非理想開關（MOSNI / PMOSNI / IGBTNI）的內部閘極電壓、端電壓、端電流、瞬時功率或累積能量。能量以梯形法在每個模擬步累積；在波形視窗用游標 C1、C2 夾住一次切換，讀 Δ 即為該次 Eon 或 Eoff。探棒名稱即為波形名稱。
- `ACP` AC 掃頻探棒 — pins: n(0,2)A
  AC 掃頻輸出探棒：量測此節點（對地）相對於激勵源的頻率響應 H = V/激勵，結果顯示於波德圖。可接功率或控制節點。
- `ACP2` AC 掃頻探棒（迴路） — pins: dot(-2,0)A x(2,0)A — neg=1
  迴路增益探棒：圓點端接在激勵源注入「之後」的節點，另一端接注入之前的節點，直接量測閉迴路系統的迴路增益，波德圖會標示穿越頻率與相位裕度。

## 電源 › 電壓源

- `VDC` 直流電壓源 — pins: +(0,-2)A -(0,2)A — V=10V
  直流源：固定振幅。 可用於功率電路或控制電路；用於控制電路時負端必須接地。
- `VSIN` 正弦電壓源 — pins: +(0,-2)A -(0,2)A — Vm=10V, f=60Hz, ph=0deg, off=0V, ts=0s
  正弦波源：v = Vm·sin(2π·f·t + θ) + Voffset，t < Tstart 時為 0。也可當作 AC 掃頻的激勵源（以元件名稱指定）。 可用於功率電路或控制電路；用於控制電路時負端必須接地。
- `VTRI` 三角波電壓源 — pins: +(0,-2)A -(0,2)A — Vpp=1V, f=10kHz, D=0.5, off=0V, ph=0deg
  三角波源：由 Voffset 開始以上升時間比 D 上升到 Voffset + Vpp 再下降，常作為 PWM 載波。轉折點會被設為模擬斷點，與比較器交越內插搭配可得到精確 PWM。 可用於功率電路或控制電路；用於控制電路時負端必須接地。
- `VSAW` 鋸齒波電壓源 — pins: +(0,-2)A -(0,2)A — Vpk=1V, f=10kHz, off=0V, ph=0deg
  鋸齒波源：在一個週期內由 Voffset 線性上升到 Voffset + Vpeak 後瞬間歸零。 可用於功率電路或控制電路；用於控制電路時負端必須接地。
- `VSQU` 方波電壓源 — pins: +(0,-2)A -(0,2)A — Vpp=1V, f=10kHz, D=0.5, off=0V, ph=0deg
  方波源：週期開始時為高電位 Voffset + Vpp，持續 D·T 後變為低電位 Voffset。邊緣時刻精確設為模擬斷點。 可用於功率電路或控制電路；用於控制電路時負端必須接地。
- `VSTEP` 步階電壓源 — pins: +(0,-2)A -(0,2)A — V=1V, ts=1ms
  步階源：t < Tstep 時為 0，之後為 Vstep。 可用於功率電路或控制電路；用於控制電路時負端必須接地。
- `VSTEP2` 雙準位步階電壓源 — pins: +(0,-2)A -(0,2)A — V1=0V, V2=1V, ts=1ms, tr=0s
  雙準位步階源：由 Vstep1 在 Tstep 時以 T_transition 線性轉換到 Vstep2。 可用於功率電路或控制電路；用於控制電路時負端必須接地。
- `VPWL` 分段線性電壓源 — pins: +(0,-2)A -(0,2)A — f=0Hz, vals=0 1 1 0V, times=0 1m 2m 3ms
  分段線性源：由 (Ti, Vi) 點連成的折線，可設定頻率使其週期性重複。 可用於功率電路或控制電路；用於控制電路時負端必須接地。
- `VPWL2` 分段線性（成對）電壓源 — pins: +(0,-2)A -(0,2)A — f=0Hz, pairs=(0,0) (1m,1) (2m,1) (3m,0)
  分段線性源（成對輸入）：以 (t, v) 成對的格式輸入。 可用於功率電路或控制電路；用於控制電路時負端必須接地。
- `VBAT` 直流電池 — pins: +(0,-2)A -(0,2)A — V=10V
  直流電池（理想直流電壓源，符號不同）。
- `VSIN3` 三相正弦電壓源 — pins: n(-2,0)P a(2,-1)P b(2,0)P c(2,1)P — V=380V, f=60Hz, ph=0deg
  對稱三相 Y 接正弦電壓源，n 為中性點，有圓點者為 A 相。相電壓峰值 = V·√2/√3，B、C 相分別落後、超前 120°。
- `VCCVS` 電流控制電壓源 — pins: +(0,-2)P -(0,2)P c+(-2,-1)P c-(-2,1)P — k=1
  電流控制電壓源：輸出 = k × 控制電流。兩個控制端必須跨接在一個 R/L/C 支路的兩端（相同節點），控制電流即為該支路由 c+ 流向 c− 的電流。
- `VCCVS1` 電流控制電壓源（串接） — pins: +(0,-2)P -(0,2)P in(-2,-1)P out(-2,1)P — k=1
  電流控制電壓源（串接式）：控制電流由 in 流入、out 流出（內部以 0 V 理想電流計量測），輸出 = k × 控制電流。
- `VVCVS` 電壓控制電壓源 — pins: +(0,-2)P -(0,2)P in+(-2,-1)A in-(-2,1)A — k=1
  電壓控制電壓源：輸出 = k × (v(in+) − v(in−))。控制端可接功率電路或控制電路（控制電路時使用前一步的控制值）。
- `VVCVSV` 可變增益電壓控制電壓源 — pins: +(0,-2)P -(0,2)P vin1(-2,-1)A vin2(-2,1)A — k=1
  可變增益電壓控制電壓源：輸出 = (k·vin2)·vin1，vin2 取前一步的值（假設 vin2 變化緩慢），收斂性比非線性源好。輸入為對地電壓。
- `VNONM` 非線性電壓源（乘法） — pins: +(0,-2)P -(0,2)P vin1(-2,-1)A vin2(-2,1)A — k=1
  非線性電壓源：輸出 = k·vin1·vin2，若輸入為功率節點則以牛頓法於當步求解。
- `VNOND` 非線性電壓源（除法） — pins: +(0,-2)P -(0,2)P vin1(-2,-1)A vin2(-2,1)A — k=1
  非線性電壓源：輸出 = k·vin1/vin2（上方 vin1 為被除數）。
- `VNONSQ` 非線性電壓源（平方根） — pins: +(0,-2)P -(0,2)P vin1(-2,0)A — k=1
  非線性電壓源：輸出 = k·√vin1。
- `VPOWERS` 冪次電壓源 — pins: +(0,-2)P -(0,2)P vin(-2,0)A — k=1, k1=1, k2=2
  冪次電壓源：vo = sign(vin)·k·(k1·|vin|)^k2。
- `VGDC` 接地直流源（圓形） — pins: n(0,1)A — V=10V
  單端直流電壓源，參考點為地；可用於功率電路或控制電路（例如控制參考值）。
- `VGDCT` 接地直流源（T 形） — pins: n(0,1)A — V=10V
  單端直流電壓源（T 形符號），參考點為地。
- `VRAND` 亂數電壓源 — pins: +(0,-2)A -(0,2)A — Vpp=1V, off=0V, seed=1
  亂數源：每個時間步產生 Vpp·n + Voffset，n 為 0~1 的亂數。 可用於功率或控制電路。
- `VMATH` 數學函數電壓源 — pins: +(0,-2)A -(0,2)A — expr=sin(2*pi*60*t), ts=0s
  數學函數源：以 t 的運算式定義輸出，例如 sin(2*pi*60*t+2.09)。 可用於功率或控制電路。
